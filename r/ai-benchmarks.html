How AI Is Measured

A benchmark is a fixed set of questions with an automatic grader. This deck shows what the questions look like, who leads today, what testing costs, and where the scores break.

Use ← → keys or swipe

01 · Example item

An expert trivia question

Humanity's Last Exam has 2,500 questions across more than 100 subjects, written by nearly 1,000 experts at 500+ institutions [1]. Two of its public samples, paraphrased:

  • Classics: here is a Roman tombstone inscription in Palmyrene script, with a transliteration. Translate it.
  • Ecology: given a photo of a hummingbird bone, how many paired tendons does this sesamoid bone support?

Answers are short or multiple choice, so a script can grade them.

02 · Example item

A real bug report

  • SWE-bench gives the model a GitHub issue from a popular open-source Python project, plus the code at that point in time [2].
  • The model must write a patch. Hidden tests from the real fix decide pass or fail.
  • The "Verified" subset is 500 tasks that humans checked for clear wording and fair tests [2].

03 · Example item

A colour-grid puzzle

  • ARC-AGI shows a few pairs of small coloured grids: an input and the output it turns into.
  • The model must infer the rule (for example, "fill every enclosed shape with the colour of its border") and draw the output for a new input.
  • ARC Prize reports a human panel solving 100% of ARC-AGI-2 tasks at about $17 per task [3].

08 · Agents

Task length doubles about every four months

Length of task (in human working hours) a model finishes half the time. METR's fitted doubling time since 2023 is about 129 days [7].

METR says results above 16 hours are unreliable with its current task suite [7].

09 · Cost

Similar scores, ten times the bill

Cost of one full SWE-bench Verified run (500 tasks, same simple agent), with score [2].

  • The HAL agent leaderboard spent about $40,000 on 21,730 runs across 9 models and 9 benchmarks [11].
  • One task in Artificial Analysis's index averages $1.73 for GPT-6 Astra (high) [12].

10 · Limit

Contamination and bad answer keys

  • In February 2026 OpenAI stopped reporting SWE-bench Verified. Models could reproduce original fixes from memory, and at least 59.4% of audited failures had tests that rejected correct code [8].
  • FutureHouse estimated 29% of HLE's text-only chemistry and biology answers conflict with published research. The HLE team's own review put it near 18% [9].
  • Once a test is public, it ends up in training data.

11 · Limit

Gaming the leaderboard

  • Meta tested 27 private variants on Chatbot Arena before Llama 4 and could publish only the best [10].
  • Google and OpenAI each received about 20% of all Arena data. 83 open-weight models shared about 30% [10].
  • HAL caught agents searching HuggingFace for the benchmark instead of solving the task [11].
  • As METR's suite saturates, results swing with analysis choices. One fix cut recent horizons by up to 20% [13].

12 · Reading scores

Why one number misleads

  • Same model, different bar: Claude Mythos Preview has a 17-hour horizon at 50% success, but 3 hours at 80% [7].
  • Same model, different harness: Claude 4.5 Opus scores 79.2% on SWE-bench Verified inside one agent and 76.8% inside a basic one [2].
  • Same score, different cost: 75.8% cost $37 for one model and $178 for another [2].
  • Confidence matters: GPT-6 Astra's HLE calibration error is 39 points, so its stated confidence often misses its real accuracy [6].
